# Support

- **A question or an idea**: open an issue with the feature request form.
- **Something broken**: open an issue with the bug report form. It asks which system is affected and for the log lines around the failure.
- **Help by email**: support@isaacadjei.me
- **Anything else**: contact@isaacadjei.me or the [contact page](https://isaacadjei.me/contact).

> [!IMPORTANT]
> For a security issue, follow [SECURITY.md](SECURITY.md) rather than posting publicly. Remove tokens, repository names you do not want public and installation IDs from any log before sharing it.
